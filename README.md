# goit-js-hw-12

Image search application using Pixabay API.

## Features
- Search images by keyword
- Pagination with "Load more" button
- Smooth scroll after loading new images
- SimpleLightbox for image preview
- iziToast notifications
- async/await + Axios

## Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. **Важливо!** Відкрий `src/js/pixabay-api.js` і заміни `YOUR_PIXABAY_API_KEY` на свій ключ з [Pixabay](https://pixabay.com/api/docs/).
4. Запусти проєкт:
   ```bash
   npm run dev
   ```

## Build
```bash
npm run build
```
